# Sales Performance Dashboard | Microsoft Excel

## Project Overview

This project presents an Excel-based Sales Performance Dashboard designed to analyze sales data and summarize key business performance metrics. It demonstrates the use of Excel data analysis tools, calculated fields, Pivot Tables, and dashboard visualization.

## Objectives

* Analyze overall revenue and gross profit.
* Evaluate gross profit margin and cost of goods sold (COGS).
* Track units sold and order volume.
* Explore sales performance across regions, countries, sales channels, customer types, and product categories.
* Present key metrics in a dashboard for easier business decision-making.

## Tools & Skills Used

* **Microsoft Excel**
* **Pivot Tables**
* **Excel formulas and calculated fields**
* **Data organization and preparation**
* **KPI analysis**
* **Dashboard design and data visualization**

## Key Performance Indicators (KPIs)

* Total Revenue
* Total Gross Profit
* Gross Profit Margin
* Total Units Sold
* Order Count
* Cost of Goods Sold (COGS)

## Dataset Overview

The workbook contains sales transaction data with fields including:

* Order Date, Year, Quarter, and Month
* Region and Country
* Sales Channel and Customer Type
* Product Category and Product
* Units Sold, Unit Price, and Discount
* Revenue, COGS, Gross Profit, and Gross Margin

## Project Structure

* `Ankit_Dashboard.xlsx` — Excel workbook containing the sales data, Pivot Table analysis, and dashboard.

## Key Learnings

Through this project, I practised organizing sales data, calculating business KPIs, summarizing information with Pivot Tables, and presenting performance metrics in a dashboard format.

## How to Explore

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard sheet to view the visual summary.
4. Explore the Pivot Table and Data sheets to understand the analysis and underlying data.
